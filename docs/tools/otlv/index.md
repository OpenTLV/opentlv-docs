# otlv CLI

`otlv` is OpenTLV's command-line tool for files, terminal inspection and automation.

- **Capabilities:** inspect and structurally validate TLV, encode and decode,
  exchange versioned JSON documents, and recover elements from damaged input.
- **Status:** available from the standalone CLI repository, versioned independently
  of Core. Supported operations and formats are documented by the selected manual.
- **Owner:** [opentlv-cli](https://github.com/OpenTLV/opentlv-cli).

## Installation and first use

Follow [CLI build and installation](../../cli/README.md#build-and-install),
then run the [first inspection](../../cli/README.md#first-inspection).
The format must be supplied explicitly; the tool does not detect it or infer
Value semantics.

## Detailed documentation

Open the [otlv manual](../../cli/README.md) for commands and examples,
the [JSON reference](../../cli/json-schema.md) for data interchange, or
[development instructions](../../cli/development.md) to build or contribute.
The manual has its own navigation and a return link to the portal.

The independent [CLI documentation entry](https://opentlv.github.io/opentlv-docs/cli/)
selects published documentation; open the
[stable CLI manual](https://opentlv.github.io/opentlv-docs/cli/stable/) for the
published stable snapshot. The selected manual above uses the exact CLI source chosen for this
portal version and remains accessible without a matching CLI release.
See [versions and releases](../../cli/releases.md) for the product's release model.
