# Component contributor guides

Choose the component you are changing. These guides are maintained by their
implementation repositories and selected at the same revisions as their public
manuals. They cover contributor tests, internal boundaries and release procedures.

<!-- opentlv-content: components -->

For public API and setup instructions, use the [Languages](../bindings/index.md)
and [Tools](../tools/index.md) catalogs.

Core contributor guidance starts with [Architecture](architecture/index.md),
[Building from Source](building/index.md) and [Testing and Quality Gates](testing.md).
The Core-hosted Go and WebAssembly guides combine language-specific setup
and development instructions; their [language entry points](../bindings/index.md)
remain available.

Migration evidence and dated validation reports are collected in
[Historical records](history.md). Independent product releases retain their
own manuals and navigation; these contributor links describe the portal's
selected source set.
