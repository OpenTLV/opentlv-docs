# Rust

The `opentlv` crate offers a safe Rust API over the OpenTLV C library.

- **Language:** Rust; supported versions belong to the [selected setup guide](../../guides/rust.md#cargo-setup).
- **Status:** available as an experimental in-tree binding. The selected guide
  documents local path dependencies, not a crates.io release.
- **Owner:** [Core's Rust binding](https://github.com/OpenTLV/opentlv/tree/main/bindings/rust).

## Installation and first use

Follow [Cargo setup](../../guides/rust.md#cargo-setup) and the linked quick
start for the native toolchain, dependency and library selection requirements.

## Detailed documentation

Read the [Rust manual](../../guides/rust.md) and
[development guide](../../development/rust.md), which also explains local
Rustdoc generation. Check the [capability matrix](../../concepts/bindings.md)
for API coverage. These documents remain Core-owned; no independent Rust
documentation release is implied.
