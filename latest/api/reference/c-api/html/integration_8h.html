Detailed Description

Public lifetime and metadata boundary for Document consumers. Integrations combine these operations with public node navigation, identity, revision and mutation APIs. No private node or Document layout is exposed.

int tlv_document_callback ( tlv_document_t *  document,
int  active 
)

Enter or leave a nested callback lifetime guard.

Parameters
documentRequired live Document; callers must balance every entry with one exit, including on failure. This API does not synchronize threads.
activeNonzero enters; zero exits an existing guard.
Returns
Zero on entry or a nested exit. Outermost exit returns zero when unchanged, one after deferred erasures, or two after deferred destruction.
Note
While guarded, fallible edits fail with INVALID_STATE. Erase/free defer reclamation until the outermost exit, preserving borrowed nodes and Values. An exit returning two destroys the Document: do not access it again. An exit returning one invalidates retained traversal state. Revision and retirement epoch advance through the ordinary mutation operations during reclamation. The caller must keep nesting representable in size_t and must not exit an unguarded Document. No allocation is performed by entry or an unchanged exit.

Copy the effective Document options for an integration.

Parameters
documentLive Document, or NULL for an all-zero result.
Returns
Options with the actual allocator, including the default allocator. The allocator pointer borrows the Document; copy its value if needed beyond this call. Format and allocator contexts retain their original lifetimes.
Note
Temporary integration storage must use nonzero allocation sizes and release non-NULL allocations through the same allocator before destruction.
