inlinestatic

Callback control statuses are opt-in. Ordinary provider failures retain their identity; an unknown discriminator is a provider contract defect.

Parameters
[in]resultResult returned by a provider.
[in]allow_endNonzero only when the callback contract permits TLV_END.
Returns
The original success/error, permitted TLV_END, or TLV_ERR_CALLBACK for unsupported control statuses and unknown values.

No default: -Wswitch must diagnose newly added result enumerators.
