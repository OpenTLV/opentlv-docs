 Shared, protocol-independent UTF-8 validation. No allocation or recursion. Input may be NULL only with zero length. Rejects malformed/overlong UTF-8, surrogates and code points above U+10FFFF, accepting embedded U+0000. Returns TLV_OK or TLV_ERR_INVALID_VALUE.
