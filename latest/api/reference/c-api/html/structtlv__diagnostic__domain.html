Detailed Description

Static producer descriptor; it and its strings must outlive every frame. IDs 1..255 identify generic modules, 256..511 builtins, 512..32767 are reserved, and 32768..65535 identify external producers. External identity uses both id and name. Zero is invalid. Names and callbacks are borrowed; optional lookups return static strings and must tolerate unknown IDs.
