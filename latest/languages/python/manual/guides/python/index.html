    Using OpenTLV from Python¶

    Start with setup below, then run the Python quick start for input, expected output and the public API. You can use this guide without studying native C implementation contracts.

    The opentlv package is an experimental Python binding for OpenTLV. It binds Reader, Writer, Document/Node, Element, Tag, Format (including custom composed formats), LengthSchema/StructureSchema (with a reusable CheckedStructureSchema), ValueConstraint, compiled Query programs and the OpenTLVError exception hierarchy, plus the generic Value and structure codecs (see Codec). For layout and build details, see Python bindings.

    Setup¶

    The standalone package enables every supported Core capability and format. BER, CER, DER, EMV, LLDP and NFC providers, fixed formats, Document and the existing EMV amount functions are available. Native HAS_* flags remain unchanged and report enabled providers. Reduced-feature Python packages are not supported.

    The opentlv distribution contains both the native _opentlv extension and the opentlv package. It is not published to PyPI yet. Install it from a checkout of opentlv-python:

    git clone https://github.com/OpenTLV/opentlv-python.git
cd opentlv-python
python -m venv .venv
# Activate the virtual environment for your shell before installing.
python -m pip install .

    This requires Python 3.11 or newer, Git, CMake 3.26 or newer and a C99 compiler; see Build. The build selects its pinned Core dependency independently of a sibling checkout.

    import opentlv

print(opentlv.__version__)  # Python binding version, independent of Core

    Runnable round-trip version: quick_start.py (python examples/quick_start.py from the repository root).

    Reading¶

    Reader is a Python iterator over Element values. Each Element has a Tag and a value that is a memoryview of retained immutable input storage. Sequential Reader treats constructed Values as opaque. Use TreeReader for canonical preorder traversal, limits and subtree skipping. Both Readers support incremental windows and Visitors; QueryMatcher adds resumable Query processing. See the Reader and Query facade contract.

    import opentlv

data = bytes([0x01, 0x02, 0xAA, 0xBB, 0x02, 0x00])
for element in opentlv.Reader(data):
    print(element.tag, bytes(element.value))

    data may be bytes, bytearray, memoryview, or any other buffer-protocol object. Immutable bytes are retained without copying; other inputs are snapshotted into immutable bytes. Returned views keep their storage alive across Reader destruction and input replacement. Reader(data) uses opentlv.Format.BER; pass format= for another wire format, for example opentlv.Reader(data, opentlv.Format.BER), or an opentlv.FixedFormat(tag_size, length_size, byte_order="big") for a runtime-configurable fixed-width tag and length (equivalent to the C tlv_fixed_format_t). Custom formats are composed from the generic field encodings.

    Reader.read_source() returns a Decoded with the original encoding and its Layout, which Writer.preserve() needs. Reader.read_element() pulls the next Element without building them, which is cheaper when only the content is inspected; its length is then empty. opentlv.read(data) and opentlv.read_element(data) decode one element without a Reader; read_element returns the element and the consumed byte count.

    Runnable version, parsing a nested BER document and handling truncated input: parse.py (python examples/parse.py).

    Writing¶

    Writer encodes into a buffer it owns and grows as needed, so write never fails for lack of space, only for an error the format itself reports (for example an unsupported tag size).

    import opentlv

writer = opentlv.Writer()
writer.write(opentlv.Tag(b"\x50"), b"VISA")
data = writer.bytes()

    write accepts a Tag or raw bytes for the tag, and any buffer-protocol object for the value; write_element appends a decoded Element, for example one produced by a Reader, so reading and re-writing round-trips. Like Reader, Writer(format=...) selects the wire format. opentlv.encoded_size(tag, value_length, format=...) computes an element's encoded size without writing it.

    Writer(buffer=storage) instead writes into caller-owned storage that never grows and cannot be resized while the Writer exists. remaining reports the space left. A write that does not fit raises BufferTooShortError with required and available and leaves the position and written output unchanged. copy_encoded(data) appends raw bytes, and preserve(decoded) appends an element read with read_source() in its original encoding after C checks that its content is unchanged. opentlv.write_element(storage, element, format, offset=...) encodes one element into caller storage without a Writer and returns its size; opentlv.element_encoded_size(element, format) measures it first.

    Runnable versions: write.py builds a nested BER document bottom-up (python examples/write.py); writer.py shows the growable buffer handling a value far larger than its initial capacity, and a genuine format error (python examples/writer.py); stream.py streams elements into a fixed buffer, preserving one unchanged and stopping when the buffer is full (python examples/stream.py).

    Custom formats¶

    Format.fields(tag, length, ...) composes a Format from one identifier encoding and one length encoding, without writing C. The encodings mirror tlv/field/*.h: FixedIdentifier, VariableIdentifier (with an optional IdentifierPolicy), FixedLength, VariableLength (with an optional LengthPolicy) and EscapedLength. element_order="ltv" places the length first, length_scope="tag_and_value" counts the identifier too, tag_only= lists identifiers without Length and Value, and constructed=ConstructedBit(...) classifies nesting; without it every Value is opaque. Format.variable() and Format.escaped() are the same composition restricted to variable or escaped encodings, and Format.packed(header_size=..., tag=PackedField(...), length=PackedField(...)) packs Tag and Length bits into one header integer.

    import opentlv

# One-byte tag; length below 0xFF inline, otherwise 0xFF and two bytes.
format = opentlv.Format.escaped(
    opentlv.FixedIdentifier(1), opentlv.EscapedLength(0xFF, 2),
    constructed=opentlv.ConstructedBit(0, 0x80, 0x80))
wire = format.encode(b"\x01", b"Hello")
document = opentlv.Document(wire, format)

    The binding passes the configuration to Core's own compositions, which validate it and raise InvalidArgError for an invalid one; Python only checks types and ranges. The result is a ComposedFormat usable anywhere a builtin Format is: Reader, TreeReader, Writer, TreeWriter, Document, Query and schemas. Equal configurations return the same object while it is alive, so a Query compiled with one is compatible with a Document parsed with another.

    A PackedField also reads and writes its bits directly, outside a Format, through tlv_packed_field_read() and tlv_packed_field_write(). field.read(data, header_size=1) extracts it from the header_size-byte integer at the start of data, and field.write(data, value, header_size=1) inserts it into a writable buffer in place, keeping every bit outside the field; byte_order="little" selects the other byte order. A value wider than bit_width raises ValueOverflowError, short data TruncatedError (read) or BufferTooShortError (write), and a failed write leaves data unchanged.

    priority = opentlv.PackedField(bit_offset=5, bit_width=3)
header = bytearray(b"\xa4")
priority.read(header, header_size=1)      # 5
priority.write(header, 2, header_size=1)  # header is now b"\x44"

    Every Format, builtin, FixedFormat or composed, also exposes the C tlv_format_t operations directly: decode(data) returns a Decoded for one element, measure(tag, value) an Encoding of header, value, trailer and total sizes, encode(tag, value) the encoded bytes, and can_read/can_write the descriptor's capabilities. Their errors carry the Format's own detail in operation, region, offset, required and the tag, length and value offsets.

    Runnable version, a proprietary format through Tree Writer, Reader, Document and Query: compose.py (python examples/compose.py).

    Generating wire data¶

    Generator(format, candidates, max_elements=..., max_depth=..., max_value_size=..., max_case_size=..., seed=...) produces reproducible test streams for property-based tests and fuzz corpora through Core's tlv_generate(). Each GeneratorCandidate(tag, min_value_size, max_value_size) names one identifier and its inclusive Value size interval; constructed identifiers, as the Format classifies them, receive generated children. generate(case_index) returns one nonempty complete stream that decodes and re-encodes byte-exactly, and generate_into(buffer, case_index) writes it into caller storage of at least max_case_size bytes and returns its size.

    import opentlv

generator = opentlv.Generator(
    opentlv.Format.BER,
    [opentlv.GeneratorCandidate(b"\x5a", 0, 16), opentlv.GeneratorCandidate(b"\x70", 0, 64)],
    max_elements=8, max_depth=2, max_value_size=64, max_case_size=512, seed=1)
cases = [generator.generate(index) for index in range(100)]

    The same Generator.VERSION, Format, candidates, limits, seed and case index always produce the same bytes, independent of earlier calls, so a failing case is replayed from its index. The cases are wire data with arbitrary primitive Values, not Schema- or Codec-valid content; leave stream terminators and identifiers that need contextual ordering out of the candidates. Core validates the configuration on each call: invalid limits or candidates raise InvalidArgError, a Format that cannot read and write or max_depth above 64 raises UnsupportedError, and candidates the Format rejects can end in LimitError. The binding sizes and owns the scratch workspace; workspace_size reports it.

    Runnable version, a round-trip property over 100 cases of a custom format: generate.py (python examples/generate.py).

    Validating¶

    LengthSchema is a per-tag length table whose lookup and length constraints delegate to the canonical C Schema API:

    from opentlv import LengthRule, LengthSchema, Tag

tag = Tag(b"\x9f\x02")
schema = LengthSchema([LengthRule(tag, min_length=6, max_length=6)])
schema.validate_length(tag, 6)

    StructureSchema validates framing, nesting, lengths, occurrence counts and child membership against a table of StructureRules, running the C library's validator (tlv_schema_validate):

    from opentlv import Format, StructureRule, StructureSchema, Tag

tag = Tag(b"\x9f\x02")
schema = StructureSchema([StructureRule(tag, min_occurs=1, max_occurs=1,
                                         min_length=6, max_length=6)])
schema.validate(data, format=Format.BER)

    A StructureRule is optional (0 to unrestricted occurrences) and accepts any length, kind and children by default; pass keyword arguments (min_length, max_length, min_occurs, max_occurs, kind, children) to restrict it, where Rust's builder methods (.length(), .occurs(), .kind()) become keyword arguments on the constructor instead. children nests another StructureSchema for the value's own elements and implies Kind.CONSTRUCTED; which tags are constructed depends on format (BER, CER and DER nest by their constructed bit; Fixed formats never nest, so children only applies to BER, CER or DER data). schema.validate() raises InvalidSchemaError for an invalid definition, or SchemaError for input violations, including lengths and required absence. Inspect kind and anchor with the optional offset: missing content has kind="missing", while an invalid definition has no input offset.

    Every validate() call checks the whole definition again before reading input. To validate many inputs against one schema, schema.check() checks the definition once through tlv_schema_prepare() and returns a CheckedStructureSchema. Its validate() and validate_diagnostics() take the same arguments, run tlv_schema_validate_checked() and tlv_schema_validate_all_checked(), and never raise InvalidSchemaError; runtime limits are still checked on every call. The handle owns a native copy of the whole schema graph taken at check(), so later changes to the StructureSchema or its rules do not affect it; check again after changing the definition. schema.check_definition() runs only the definition check (tlv_schema_check()) and raises the same InvalidSchemaError, with definition_index, as check().

    checked = schema.check()
for message in messages:
    checked.validate(message, format=Format.BER)

    ValueConstraint binds tlv_value_constraint_t, a constraint on one decoded signed 64-bit value rather than on TLV bytes, such as an ASN.1 INTEGER range or named numbers; pair it with a codec's decode. ValueConstraint.range(min_value, max_value) permits an inclusive range and ValueConstraint.allowed(values) a set of integers, or a mapping of integers to display names. Core checks the definition on construction (tlv_value_constraint_check()), raising InvalidSchemaError for reversed bounds. validate(value) raises SchemaError for a violation (tlv_value_constraint_validate()), and name(value) returns an allowed value's name or None (tlv_value_constraint_name()).

    from opentlv import ValueCodec, ValueConstraint

color = ValueConstraint.allowed({0: "red", 1: "green", 2: "blue"})
value = ValueCodec.INT64_MINIMAL_BE.decode(b"\x01")
color.validate(value)
color.name(value)  # "green"

    Runnable version, validating the document parse.py reads, and rejecting an incomplete one: validate.py (python examples/validate.py). batch.py validates a batch of messages against a checked schema and evaluates one compiled Query over each (python examples/batch.py).

    Generic Definition registries¶

    Definition(tag, name=None) describes an identifier independently of Schema or Codec. DefinitionRegistry(definitions).find(tag) calls the canonical C lookup and returns the first matching record or None. Records own immutable identifier bytes and names, so returned definitions survive the registry.

    Codec¶

    Codecs convert one element's Value bytes through the public C descriptors. They never select themselves by tag: choose the codec for each Value explicitly. Every Value codec has decode, encode, encoded_size and encode_into for conversion, measurement and caller-owned output.

    Codec Python value C descriptor
    NumberCodec(encoding, width, digits) int (uint64) tlv_number_decode/tlv_number_encode
    SchemaNumberCodec(rule, encoding, width, digits) int (uint64) tlv_schema_number_codec()
    ValueCodec.UINT8, UINT16_BE, UINT16_LE, UINT32_BE, UINT32_LE int of exactly that width tlv_codec_uint8, tlv_codec_uint16_be, ...
    ValueCodec.INT64_MINIMAL_BE signed int, shortest two's complement tlv_codec_int64_minimal_be
    ValueCodec.BYTES bytes tlv_codec_bytes
    ValueCodec.IPV4, ValueCodec.IPV4_LIST IPv4Address, tuple of them tlv_codec_ipv4, tlv_codec_ipv4_list
    TextCodec(alphabet, width, zero_padding) ASCII str tlv_text_decode/tlv_text_encode
    DigitsCodec(width) decimal digit str with leading zeros tlv_digits_decode/tlv_digits_encode

    NumberCodec supports BIG_ENDIAN, LITTLE_ENDIAN and BCD; BCD requires digits precision. TextCodec accepts TextAlphabet.ASCII_PRINTABLE or ASCII_ALNUM; a nonzero width is fixed, and zero_padding strips or adds trailing zero bytes. DigitsCodec packs digits high nibble first with trailing F padding, unlike numeric BCD. Width zero selects minimal encoding for all three. IPv4 encoding accepts anything IPv4Address accepts; decoded lists keep order and duplicates.

    SchemaNumberCodec is a NumberCodec whose Value lengths a LengthRule limits, through Core's tlv_schema_number_t. Decoding validates the length against the rule before converting; encoding with width zero picks the shortest width the rule permits, and a fixed width the rule rejects raises SchemaError instead of changing width. With flags=1 (endpoints only), SchemaNumberCodec(LengthRule(tag, 2, 4, flags=1)).encode(0x10000) produces four bytes, since three are not permitted.

    from opentlv import DigitsCodec, TextCodec, ValueCodec

DigitsCodec().decode(b"\x01\x23\x4f")             # "01234"
TextCodec(width=4, zero_padding=True).encode("ab")  # b"ab\x00\x00"
ValueCodec.IPV4_LIST.decode(bytes.fromhex("c0000201c6336401"))
# (IPv4Address('192.0.2.1'), IPv4Address('198.51.100.1'))

    Conversion errors raise the corresponding OpenTLVError subclass. Integers outside the codec's C type raise OverflowError during representation adaptation. A failed encode_into leaves its output unchanged.

    StructureCodec(format, schema, decode=..., encode=...) maps one complete TLV sequence to one application object. C validates framing, nesting, limits and the optional StructureSchema or CheckedStructureSchema before decode(data) sees the bytes. It validates what encode(value) returns before handing it back, so a schema violation in produced bytes raises with an output location. encode runs once per operation. A missing direction raises UnsupportedError, and callback exceptions propagate unchanged.

    from opentlv import Reader, StructureCodec, StructureRule, StructureSchema, Tag, ValueCodec

schema = StructureSchema([StructureRule(Tag(b"\x5a"), min_occurs=1, max_occurs=1,
                                        min_length=2, max_length=2)])
port = StructureCodec(
    schema=schema,
    decode=lambda data: ValueCodec.UINT16_BE.decode(next(iter(Reader(data))).value),
    encode=lambda value: b"\x5a\x02" + ValueCodec.UINT16_BE.encode(value))
port.decode(bytes.fromhex("5a021f90"))  # 8080
port.encode(443)                        # b"\x5a\x02\x01\xbb"

    opentlv.codec also binds tlv_emv_codec_amount for EMV format n12 amounts:

    from opentlv import codec

codec.encode_amount(12345)            # b"\x00\x00\x00\x01\x23\x45"
codec.decode_amount(b"\x00\x00\x00\x01\x23\x45")  # 12345

    Builtin protocol codecs (ASN.1, Bluetooth, LLDP, and EMV dates, Track 2, AFL, CVM results and cryptogram information, among others) remain binding gaps. They must be exposed by wrapping the public C descriptors rather than reimplementing their conversion logic. OpenTLVError.code contains the shared tlv_result_t value; codec_detail retains operation, original provider result, contract violation and delegated cause when supplied by C. Its schema entry is an owned SchemaDiagnostic.

    Runnable version, decoding and encoding an EMV "Amount, Authorised" element: codec.py (python examples/codec.py). value_codecs.py decodes digits, text and an IPv4 list from one message (python examples/value_codecs.py).

    Documents¶

    Reader retains immutable input or snapshots mutable buffers, and Writer uses managed output storage. Document is a separate, allocating convenience layer for changing an existing message. It parses input into an owned tree of Nodes that can be searched, changed, extended and shortened, then encoded again:

    from opentlv import Document, Tag

with Document(data) as document:
    node = document.first
    node.value = b"\xcc"                      # replace a value
    document.insert(Tag(b"\x02"), b"\xaa")     # append a new top-level element
    encoded = document.encode()

    Navigate with document.first/for node in document (top-level nodes, in encoding order), node.first_child/for child in node (a constructed node's children), node.next/node.parent, or search with document.find(tag, parent=...), node.find(tag) or document.find_path("6F/A5/50"), a path query (a /-separated path of hexadecimal tags). document.visit(query, callback) calls callback(node) for every node the path query addresses, in Document order, through tlv_document_query_visit(); query is a Query or its text, and the callback returns Visit.CONTINUE, STOP, ERROR or None. The document cannot be modified or closed during the callbacks. document.insert(tag, value, parent=..., before=...) inserts a new element; assigning node.value replaces one. For both, a value of a tag the document's reader format treats as constructed (BER, CER and DER, by their constructed bit) is parsed as nested elements, the same way parsing does. node.erase() removes a node and its descendants. Every modification either succeeds completely or leaves the document unchanged, and raises an OpenTLVError subclass on failure, the same as Reader/Writer.

    A document owns every tag and value it holds â€” the only part of OpenTLV that allocates beyond a Python object's own memory â€” so close it deterministically with close() or a with block instead of waiting for garbage collection when that matters, for example for a large document. A node stays valid until it or an ancestor is erased, its parent Value is replaced, or its document is closed. Invalid access raises ValueError before native access. Replacing a node's own Value leaves that node usable; its old children become invalid only after successful replacement. Unrelated handles remain valid. An applied QueryExecution.edit_document() invalidates every earlier node.

    document.revision increases with every successful insert, erase or Value replacement and stays the same after a failed edit, so comparing two values detects any change. With Document(data, retain_source_locations=True), node.source_location is a SourceLocation with the node's offset and header_size in the parsed input, each None when unknown. Replacing a node's Value removes them from it and its ancestors, inserting or erasing a child removes them from its ancestors, and nodes created by edits have none; unaffected nodes keep their original coordinates.

    Runnable versions: document.py replaces a value and appends an element in an existing message (python examples/document.py); query.py addresses a deeply nested element by path instead of navigating node by node, including a malformed query and a query with no match (python examples/query.py); audit.py validates a decoded INTEGER against named numbers, changes a packed header flag and reports the revision and original location of the changed element (python examples/audit.py).

    Error handling¶

    Every reading or writing failure raises a subclass of opentlv.OpenTLVError, one per C TLV_ERR_* code (TruncatedError, BufferTooShortError, InvalidLengthError, SchemaError, and so on), so callers can catch a specific error type or the base class. OpenTLVError.code is the raw result code, and str(error) is the C tlv_result_string text. When the C API reports structured diagnostic detail for the failure, offset, expected, actual, operation and tag carry it, for both a Reader and a Writer failure; length, required and available carry buffer bounds (length is Writer-only). Fields the failure does not report are None. When C tracked the enclosing tags, path holds their bytes and path_text Core's tlv_diagnostic_path_string() text, such as "6F > A5", ending in " > ..." when outer tags were omitted.

    Query failures retain common location, severity, path, path_omitted and contexts even without a Reader cause. error.query["query_kind"] is a QueryErrorKind, for example QueryErrorKind.SYNTAX; its label property returns the C spelling. error.query["expression"] is the related expression Location, with kind unknown when the expression span is error.location itself; conversion detail is error.codec_detail. A Schema Query failure's error.schema holds only the assertion's kind, kind_name, tag and field, and is None for any other failure; its location, path and expected text are the error's own. A rejected path text raises InvalidSyntaxError (or LimitError) with Query detail and no Reader operation. Path text is parsed with its explicit length (tlv_query_parse_n()), so an embedded NUL or a non-ASCII character is a syntax error at its byte offset. Codec and Schema categories are typed too. See the binding diagnostic reference.

    try:
    list(opentlv.Reader(truncated))
except opentlv.TruncatedError as error:
    print(f"{error} at offset {error.offset} ({error.operation})")

    Reader yields elements until the first error, then raises StopIteration on every further call instead of retrying: the underlying C reader does not advance past malformed input.

    Relationship to the C API¶

    _opentlv, installed by the same opentlv distribution, is a native extension written directly against the CPython C API (no pybind11, cffi or Cython) and the CPython Limited API, declaring and calling the public OpenTLV C API; opentlv wraps it and contains no C API calls of its own, the same split as the Rust opentlv-sys/opentlv crates. Reader and TreeReader retain native C cursors for incremental input and canonical traversal. Writer keeps one C tlv_writer_t session over an exported writable buffer, so its position and remaining capacity are C's. With buffer=..., output capacity is fixed; without it, a native capacity diagnostic moves the session to a larger owned bytearray, and C copies the written prefix. StructureSchema serializes its Python-owned rules (including nested children schemas) into an ephemeral C rule tree for the duration of one structure_validate() call, built and freed with plain malloc/free; CheckedStructureSchema instead keeps that tree and its tlv_schema_checked_t handle in a capsule for as long as it lives; LengthSchema likewise marshals its rules and delegates lookup and length constraints to tlv_schema_find and tlv_schema_validate_length. Rule flags and length multiples use the same C semantics. Value codecs and codec.decode_amount/encode_amount call tlv_codec_decode/tlv_codec_encode with the public descriptor or a call-local configured one; StructureCodec calls tlv_structure_decode/tlv_structure_encode with C callbacks that invoke its Python functions. opentlv.Document wraps a tlv_document_t* in a PyCapsule that frees it (tlv_document_free()) when the capsule is garbage collected or close() drops Python's only reference to it. Node retains its Document, its internal pointer and the identity Core assigned to that node, which is never reused. Before using the pointer it compares the Document's tlv_document_retire_epoch() with the epoch it last saw; only after a change does tlv_document_node_identity() locate the address without dereferencing it. This protects aliases and descendants from use after erasure, replacement or close, even when an allocation is reused. A Query edit additionally advances a binding generation that invalidates every earlier Node, because the edit reports only how many targets it applied. Remaining parity gaps are listed in the binding capability matrix.

    Tree measurement, preservation and materialization¶

    TreeWriter.measure(items, capacity, format, ...) accepts preorder tuples (Element, depth, constructed). It calls C measurement and returns the staged encoded bytes; their length is the exact size. Workspace errors expose required_data and required_scratch lower bounds. A retry needs a fresh source. Reader.read_source() results expose preserve() and preserve_into(storage); Writer.preserve(decoded) appends the unchanged original representation. All equality checks and byte copying are performed by C: preserve_into calls tlv_source_preserve() directly, and a short destination raises BufferTooShortError with required and available and leaves it unchanged.

    DocumentBuilder(reader) consumes a fresh TreeReader incrementally. DocumentBuilder(reader, next_subtree=True) consumes only its next subtree. Call consume() until a Document is returned; NeedMoreDataError permits reader.set_input(...) and retry. Use a with block or close() to discard an unfinished build. Active builders prevent other cursor traversal operations.

    Document.encode(format) and Node.encode(format) support conversion to a compatible destination Format without changing the stored tree. encoded_size_as(format) measures the same destination encoding.

    Compiled Query¶

    QueryProgram(text, format=..., variables={"minimum": int}, names=...) owns an immutable compiled C program. QueryProgram.load(image, ...) validates a same-release image using its original options; image(), format() and explain() expose copies or descriptions. info reports native requirements. Declarations accept int, bytes and str; bind actual values through an independent execution rather than interpolating Query text. Compile a program once and reuse it for any number of executions and inputs.

    With static names, or none, compilation sizes and writes the program with tlv_query_compile(); a resolve callback uses checked preparation and commit instead, described below. Both produce the same image. QueryProgram.open_plan(image, format=..., providers=..., tags=...) opens an existing image with tlv_query_plan_open(), which validates its structure without the Query frontend: no recompilation, name resolution or variable declarations. Execution still requires the plan's variables and the provider and Tag adapter IDs it was built with; missing ones raise UnsupportedError when an execution is created. plan_info reads requirements from the plan itself through tlv_query_plan_info(); its compiler scratch and optimization-history fields are zero.

    All Formats, including configured FixedFormat and composed formats, work with Query, Reader and Document. Compilation snapshots Fixed widths and byte order; equivalent Fixed or composed configurations share an owned immutable native context. Different configurations remain incompatible. tags=QueryTagAdapter(id, class_of=..., number_of=...) supplies optional semantic Tag callbacks receiving owned raw bytes and returning signed 64-bit integers. The stable nonzero ID participates in image compatibility; missing capabilities are rejected during compilation.

    Use resolve(namespace, name) instead of names for dynamic scoped resolution; return Tag bytes or None for an unknown name. Checked preparation and commit reject changed resolutions, including a different Tag with the same length. Resolver exceptions propagate unchanged. QueryDefinitionResolver({namespace: DefinitionRegistry(...)}) snapshots registries and delegates namespace and ambiguity rules to C. query_emv_resolve uses the native base EMV dictionary when that component is enabled, for example QueryProgram("//emv:PAN", resolve=query_emv_resolve).

    program.execution(max_depth=..., max_nodes=..., max_work=..., retained=True) owns bounded native state. retained=False selects S0/S1 storage. Execute through the public TreeReader pull/Visitor adapter, or evaluate a Document; results, diagnostics, limits and continuation delegate to C. Match snapshots own their bytes. reset() resets the execution in place through tlv_query_exec_reset(), keeping its program, providers, workspace and budgets and releasing pinned inputs, bindings and the Document snapshot; callback exceptions require reset before reuse. Programs and executions retain their native owners until the Python objects are collected. The consumer tests and common corpus runner exercise these APIs.

    providers={"num": QueryProvider(id, decode), ...} replaces the closed num, bcd, text or date conversion. decode(value, metadata) receives owned bytes and optional copied QueryMatch metadata; return an integer or, for text, a string. Text providers require max_result_bytes for native bounded scratch. Keep provider IDs and contracts stable when loading images. Callback exceptions propagate; callback allocations and work are outside the C engine's limits. QueryCodecProvider(id, codec) decodes Values natively through tlv_query_codec_decode(), without Python callbacks. NumberCodec and the unsigned ValueCodec members yield unsigned integers for num, bcd or date; a value above the signed 64-bit range raises InvalidValueError with codec detail. ValueCodec.INT64_MINIMAL_BE yields signed integers. TextCodec and ValueCodec.BYTES serve text, and C validates their result as UTF-8. Digit-string and IPv4 codecs have no Query representation.

    execution.feed(event) accepts canonical Tree events. Retain borrowed input as documented by the event producer; the execution pins the event bytes and original Source, preserving Layout metadata predicates. Call finish() before pulling deferred results. next_ordinal() returns an owned (QueryMatch, ordinal) from a completed retained selection, including Document selections; next() retains its checked Node behavior for Documents. After evaluate_document(), visit_document(callback) calls callback(node) for the remaining node results; STOP resumes after the delivered node on the next pull or visit. Programs that read constructed Values need an encoded Document snapshot; by default tlv_document_query_value_size() measures it only for those programs, and an explicit value_capacity that is too small raises LimitError. edit_document("remove" | "replace" | "insert_after", ...) applies a completed Document selection. target_capacity bounds target storage; a short target array reports error.applied == 0 and allows retry. Successful edits invalidate existing checked Nodes; other edit failures report partial counts.

    QuerySchema([QueryRule(context, assertion, name)], format=...) retains compiled programs and validates through validate_buffer(data, **limits) or validate_document(document, **limits). Assertions are relative Boolean Query programs. Limits bound depth, nodes, work, selected contexts and Document Value snapshots. Failures retain the rule index, Query detail and owned Schema diagnostics. Provider callbacks cannot mutate or close a Document under validation. See the release requirements.

    The separate V1 QueryMatcher preserves matching state across Visitor STOP and TreeReader input replacement. rebind(equivalent_query) copies an equivalent path without restarting a suspended traversal; a different path fails without changing state. reset() starts a new traversal and leaves Reader state to the caller. matches(tag, depth) feeds every canonical preorder item manually. Query.format() and str(query) return the canonical uppercase spelling, and query.visit_buffer(data, callback, format, max_depth=..., max_elements=...) visits matches in complete input through tlv_query_visit_buffer(), without a Reader or matcher.
