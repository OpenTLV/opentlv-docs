    Lua¶

    The opentlv module provides Lua access to TLV Readers, Writers, tree writing, Schema, Query and owned Documents. Check the manual for operations that remain unbound.

    • Language: Lua and LuaJIT; supported runtimes and build requirements belong to the selected installation guide.
    • Status: available as an experimental standalone binding, built for the Lua runtime that will load it.
    • Owner: opentlv-lua.

    Installation and first use¶

    Follow Lua build and installation, including the LuaRocks instructions. The manual setup links a runnable quick start and shows how to load the module.

    The Lua versioning guide owns runtime version inspection, package metadata and release identity.

    Detailed documentation¶

    Use the Lua manual for API contracts and examples and implementation notes for ownership and limitations. Both pages are selected from the binding repository. The API manual uses its own product menu; contributor implementation notes appear in Development.

    Independent Lua releases use /lua/<version>/, relative to the documentation site root, as described by the owner's release guide. The selected manual above remains accessible without a matching published release; a portal version is not a Lua binding release number.
